# Interactive Explanations

Browser-based Python learning apps.

- [Main page](https://interactive-explanations.vercel.app/)
- [Loop Lab](https://interactive-explanations.vercel.app/loop-lab/) — loops, ranges, and step-by-step examples.
- [Secret Machine](https://interactive-explanations.vercel.app/code-cracker/) — Caesar ciphers, Python execution, and repair exercises.

Code runs and tests stay in the browser. Generating challenges requires a student code and uses OpenAI; reruns are unlimited.
