    Curious about how this works?
    This is a Caesar cipher: move each letter by the same amount. The original program tries all 25 non-zero shifts. The animation groups real Python execution into letter-sized moments, rather than showing every instruction. It doesn’t silently fix bugs. Unusual edits may be shown as whole-message changes instead.
    Under the lid, highlighted code lines are about to execute; values show the state at that moment. The original has quirks with uppercase letters and large shifts—useful clues for a repair mission.
    Python downloads from jsDelivr on first use, so you need an internet connection initially. After loading, code and tests run locally. Your code is not sent to OpenAI. Long-running programs are stopped for you.
