① A collection gives us the items
essentials is a list. Python takes its values in order. Three items means three trips through the loop body.
② A variable names the current item
item gets a new value each turn. It’s a name we chose; thing would work just as well.
③ Indentation says what repeats
bag.append(item) is indented, so it repeats. print("Ready!") is outside the loop, so it runs once afterward.


What happens to the items on the table?The faded cards mean “already visited.” A Python for loop does not remove values from the original list. Here, bag.append(item) adds the current value to a separate list called bag. This page simulates this specific Python example.
